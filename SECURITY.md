# Security Policy

## Supported versions

Security fixes are applied to the latest version published on npm.

## Reporting a vulnerability

Please report security issues privately by email to hello@venalabs.com. Do not open a public GitHub issue for a vulnerability.

Include as much of the following as you can:

- the affected version of `@venalabs/stellar-sdk`
- a description of the issue and its impact
- steps to reproduce, or a proof of concept

We will acknowledge your report and keep you informed while we investigate. Please give us the opportunity to release a fix before any public disclosure.

There is no bug bounty program for this project.

## Scope

This policy covers the code in this repository. The API secret used to request access tokens must stay on the integrator's server (see the [integration guide](./docs/integration-guide.md)); a secret exposed in an integrator's own client-side code is outside the scope of this policy, but you are welcome to tell us about it.
